Which one do I want?

Install link: works right now. Open it on your phone, then use Add to Home screen (Android Chrome, iPhone Safari) or the install icon in the desktop address bar.

PWA zip: the same app as static files you can host on your own domain (Netlify, Render static site, any hosting).

Get Android APK / PC app: we build the real installable file in the cloud and give you a direct download. It takes about 5 to 10 minutes, so keep this page open. The .zip buttons are the source projects if you want to build them yourself.

PC app project: an Electron project that builds a real .exe installer (plus Mac and Linux builds). Push it to GitHub and run the included workflow, and the installers are built for you. You can also just install the link from Chrome or Edge on your PC.

Android/iOS project: a Capacitor project that loads your site in a real native shell. Includes a one-click GitHub workflow that builds the .apk for you.
